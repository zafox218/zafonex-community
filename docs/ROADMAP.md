# Roadmap

## Phase 1 — foundation (this scaffold)
Auth, RBAC, three catalogues, wallet, escrow checkout, admin console.

## Phase 2 — trust
Reviews tied to completed orders only, dispute flow with admin arbitration,
seller verification badges, order messaging with file attachments.

## Phase 3 — automation
Automatic on-chain deposit detection (poll a node or an explorer API),
scheduled payouts, invoice PDFs, referral program.

## Phase 4 — reach
Arabic RTL localisation, PWA install, video streaming with signed URLs,
public API and webhooks for sellers.

## Deliberately deferred
Native mobile apps, fiat rails, and an internal chat product. Each one is a
company on its own; none of them is the reason someone signs up.
